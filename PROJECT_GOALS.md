# Project goals

**Status:** Initial scope; refine as hardware, games, and add-ons are confirmed.

## Aim

Create useful dashboards for the MOZA CS Pro wheel, using SimHub telemetry and integrating with selected SimHub add-ons.

## Initial goals

- Design clear, readable dashboard layouts for the wheel's display.
- Establish and document how game telemetry flows through SimHub and the selected add-ons to the wheel.
- Confirm the dashboard format and upload workflow for the target wheel.
- Document setup, compatibility, installation, and customization so the dashboards are practical to use and maintain.
- Validate the result on the target wheel with the selected simulator and add-ons.

## Decisions to confirm

- Exact wheel model and display constraints.
- Which add-ons are in scope. AZOM and ATSR-Hub EVO are current research references, not yet confirmed requirements.
- Target simulator or simulators and the telemetry each dashboard should show.
- Dashboard design preferences and how the finished dashboards will be shared.

## Research starting point

See [the reference index](docs/REFERENCES.md). The local sample archive is kept in the ignored `references/` directory; its filename mentions CS KS PRO, so check model compatibility before using it as a direct template.
